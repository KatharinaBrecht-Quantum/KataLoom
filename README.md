# KataLoom

## Coming Soon

**`KataLoom`** is an upcoming R package.

Created as a personal homage to pixel artist **[Mark Ferrari](https://www.markferrari.com)** (*Loom*, *Living Worlds*), `KataLoom` completes a four-package computational ecosystem in R:

1. **[`octawave`](https://CRAN.R-project.org/package=octawave)** -- Simulating three-dimensional octahedral quantum wave interferences, fullerene topologies, and spatial resonance fields.
2. **[`sync3d`](https://CRAN.R-project.org/package=sync3d)** -- A decoupled WebGL rendering engine engineered to sustain smooth, synchronized multi-trace 3D animations in R.
3. **[`theaitetos`](https://CRAN.R-project.org/package=theaitetos)** -- Honoring ancient Theaetetus of Athens and Plato's Allegory of the Cave by projecting 3D Euclidean wave fields onto a 2D boundary plane.
4. **`KataLoom` *(Coming Soon)*** -- Focusing on the discrete 2D display boundary itself through ordered woven dithering matrices, cyclic palette animations, and 16-color EGA aesthetics.

> **Release Note:** `KataLoom` (`v0.1.0`) is currently in preparation for **CRAN**. The open-source code, four illustrated vignettes, and interactive studio will be published here as soon as the package is live on CRAN.
